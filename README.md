# 项目简介

## 核心功能
- 基于 YOLOv8 的目标检测系统，专用于海滩垃圾识别
- 支持 6 类垃圾检测：玻璃、塑料瓶、软包装、外卖容器、外卖杯、金属铝罐
- 提供完整的源码、数据集（2800 张标注图片）、训练好的模型及训练结果
- 支持多种输入源：单张图片、图片文件夹、视频文件、本地摄像头
- 提供交互式界面，可实时显示检测目标位置、总数及置信度
- 支持自定义检测参数：置信度阈值、IOU阈值
- 支持选择显示标签和原图
- 支持批量检测功能，可查看所有检测结果
- 包含完整项目运行教程和环境配置指南

## 适用场景
- 海滩环境监测与清理管理
- 环保数据收集与分析
- 垃圾分类与研究
- 自动化环境检测系统开发参考
- 机器学习目标检测学习项目

## 技术特点
- 使用 Python 3.9 作为开发语言
- 集成 OpenCV、PyQt5、Ultralytics、PyTorch 1.9 等技术栈
- 提供 PyCharm 和 VSCode 两种开发环境支持
- 采用图形化用户界面，操作简便
- 支持多种检测模式，适应不同应用场景
